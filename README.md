# 通讯录备份与同步 · Public information site

This repository contains only the public homepage, privacy policy and usage information for a personal contacts backup and synchronization tool.

- Homepage: https://adrian-lee-happy.github.io/contacts-sync-info/
- Privacy: https://adrian-lee-happy.github.io/contacts-sync-info/privacy/
- Usage: https://adrian-lee-happy.github.io/contacts-sync-info/terms/

No contact records, native backups, authentication credentials, account identifiers, private logs, or runtime application source code belong in this repository. The public site has no login, forms, analytics, scripts, or contact API access.

GitHub Pages availability does not establish Google OAuth domain ownership or guarantee approval. Where Google requires DNS-level domain verification, bind a domain controlled by the operator and complete the required verification. Keep the homepage and privacy policy on the same verified domain.

Publish from the `main` branch, repository root. All assets are local and there is no build step.
